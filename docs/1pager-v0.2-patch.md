```
## 인터랙션 설계

인터페이스의 기본 단위를 대화 시퀀스에서 태스크 카드로 바꾼다. 카드 한 장이 하나의 작업이며, 동시에 그 작업에 대한 대화의 컨테이너다. 한 화면 위에서 여러 카드가 동시에 굴러간다.

사용자가 새 태스크를 입력하면, 시스템은 작업판 위에 카드를 한 장 생성하고 그 카드를 해당 태스크의 대화 컨테이너로 사용한다. AI는 카드 안에서 백그라운드로 작업을 진행한다.

사용자가 카드를 열면, 그 태스크에 대한 모든 대화 이력이 보존된 채팅창이 카드 내부에 펼쳐진다. 사용자는 기존 채팅 UX에서 익숙한 방식 그대로 멀티턴 대화를 이어갈 수 있으며, 대화의 컨테이너 단위만 *세션*에서 *태스크 카드*로 바뀐다. 즉 작업판은 채팅을 대체하는 새 UX가 아니라, 채팅의 컨테이너를 작업 단위로 재정의한 것이다.

AI가 진행 도중 사용자 판단이 필요해지면 카드는 Needs You 상태로 전환되며, 사용자가 작업판을 보고 있지 않아도 OS 푸시, 브라우저 알림으로 도달한다.

사용자가 알림에서 곧장 또는 카드를 열어 응답을 입력하면, 메시지는 그 카드의 대화 이력에 추가되어 AI에게 전달되고 카드는 Working으로 복귀해 흐름을 이어간다. 모든 응답·질문·결과는 해당 카드 안에 누적되어, 같은 작업의 맥락이 끊기지 않는다.

작업이 끝나면 카드는 Done 컬럼으로 자율 이동하며, 누적된 대화 이력은 그대로 카드에 보존된다.
```
